# Research provenance

The repository records the neurosurgery implementation as clean-room code informed by mechanisms demonstrated in three related projects. This records the project's provenance statement; it is not an independent license audit. Record source revision, license and attribution before importing any third-party code.

- Orion-zhen/abliteration — contrastive residual directions, projection-style abliteration, sharded/model-aware editing concepts: https://github.com/Orion-zhen/abliteration
- p-e-w/heretic — automated candidate optimization philosophy and KL-divergence preservation objective: https://github.com/p-e-w/heretic
- jwest33/abliterator — norm preservation, null-space preservation, feature-level surgery and quality-evaluation ideas: https://github.com/jwest33/abliterator

AEGIS-LAB extends these ideas from behavioral direction editing into structural deletion: transformer blocks, MLP channels, GQA/MHA groups, and MoE experts.
